Scaffold gráfico do CertiAcademy

Use esta interface para criar cursos e simulados no padrão atual do repositório sem montar os comandos manualmente. A criação real continua acontecendo pelo scaffold oficial do projeto.

Saída

A prévia só mostra o que será criado. A criação real executa o scaffold com --write e depois roda a validação do repositório.

Como abrir esta tela corretamente
  • Não abra este arquivo HTML com duplo clique ou via file://.
  • Inicie o servidor local com node scripts/scaffold-ui-server.mjs.
  • Abra a interface em http://localhost:4173.
O que essa interface automatiza
  • Criação de curso novo com curso.html, simulados e arquivos base.
  • Criação de novo simulado em curso existente.
  • Atualização automática do card da home.
  • Atualização automática da navegação lateral dos simulados do curso.
