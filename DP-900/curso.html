O que o exame cobra

Pesos conforme o guia de estudo oficial, válido a partir de 1º de novembro de 2024.

Descrever os principais conceitos de dados 25–30%
Ver os tópicos desta área
  • Dados estruturados, semiestruturados e não estruturados
  • Formatos de arquivo e tipos de banco de dados
  • Cargas transacionais e analíticas
  • Papéis de administrador de banco de dados, engenheiro e analista de dados
Identificar considerações sobre dados relacionais no Azure 20–25%
Ver os tópicos desta área
  • Características de dados relacionais, normalização e SQL
  • Família SQL do Azure: Banco de Dados SQL, Instância Gerenciada e SQL em VMs
  • Serviços para bancos de dados de código aberto
Descrever considerações sobre o trabalho com os dados não relacionais no Azure 15–20%
Ver os tópicos desta área
  • Armazenamento de Blobs, Arquivos e Tabelas do Azure
  • Azure Cosmos DB: casos de uso e APIs
Descrever uma carga de trabalho de análise no Azure 25–30%
Ver os tópicos desta área
  • Ingestão e processamento, armazenamentos analíticos, Databricks e Microsoft Fabric
  • Diferença entre dados de lote e de streaming, e análise em tempo real
  • Visualização no Power BI: modelos de dados e escolha de visuais

Sugestão de plano de estudo

Uma etapa por área do exame, na ordem do guia oficial.

  1. 1
    Descrever os principais conceitos de dados

    Dados estruturados, semiestruturados e não estruturados. Vale 25 a 30% da prova.

  2. 2
    Identificar considerações sobre dados relacionais no Azure

    Características de dados relacionais, normalização e SQL. Vale 20 a 25% da prova.

  3. 3
    Descrever considerações sobre o trabalho com os dados não relacionais no Azure

    Armazenamento de Blobs, Arquivos e Tabelas do Azure. Vale 15 a 20% da prova.

  4. 4
    Descrever uma carga de trabalho de análise no Azure

    Ingestão e processamento, armazenamentos analíticos, Databricks e Microsoft Fabric. Vale 25 a 30% da prova.

Depois de cada etapa, faça um simulado e confira o seu desempenho: os assuntos com menor aproveitamento aparecem primeiro, e são por onde vale recomeçar.
